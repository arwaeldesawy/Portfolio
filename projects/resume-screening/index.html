AI-Powered Resume Screening

NLP-based system that ranks candidates against job descriptions using TF-IDF and machine learning classification.

Overview

NLP-based system that ranks candidates against job descriptions using TF-IDF and machine learning classification.

Results & achievements

  • Ranked resumes against job descriptions.
  • Implemented TF-IDF and cosine similarity for relevance scoring.
  • Trained and evaluated Logistic Regression and Random Forest classifiers.

Project stack

  • Python
  • NLP
  • Scikit-Learn
  • TF-IDF
  • Cosine Similarity

Technical approach

Represent & compare text

Resume and job-description text is represented with TF-IDF. Cosine similarity provides relevance scores for ranking candidates.

Train candidate classifiers

Logistic Regression and Random Forest models are trained and evaluated to support automated candidate filtering.

Project highlights

  • NLP-based system that ranks candidates against job descriptions.
  • TF-IDF vectorization and cosine similarity for feature extraction and relevance scoring.
