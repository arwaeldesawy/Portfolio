Generative AI & APIs

Prompt Library

LLM-Powered Prompt Management & Generation System

Overview

End-to-end Generative AI application managing 15 reusable prompt templates for Q&A, Summarization, and Creative Writing.

Results & achievements

  • Built a library of 15 reusable prompt templates.
  • Supported Q&A, summarization, and creative writing.
  • Connected dynamic inputs to Gemini-generated responses.

Project stack

  • Python
  • FastAPI
  • Google Gemini API
  • JavaScript
  • REST APIs

Technical approach

Choose a reusable template

A library of 15 templates covers Q&A, summarization, and creative writing. FastAPI endpoints support retrieval and filtering.

Construct & generate

The JavaScript frontend collects dynamic inputs. The API validates inputs, constructs the prompt, and integrates Google Gemini to return an LLM-generated response.

Project highlights

  • End-to-end Generative AI application managing 15 reusable prompt templates for Q&A, Summarization, and Creative Writing.
  • FastAPI REST APIs for prompt retrieval, filtering, validation, and dynamic prompt construction.
  • Integrated Google Gemini API with a JavaScript frontend for dynamic inputs and LLM-generated responses.
