Overview

AI-powered customer support workflow using n8n, an LLM API, and conversational memory for automated messaging on Telegram/WhatsApp.

Results & achievements

  • Automated customer responses with conversational memory.
  • Connected Telegram/WhatsApp messaging to an n8n workflow.
  • Added conversation logging in Google Sheets and Gmail notifications.

Project stack

  • n8n
  • LLM API
  • Telegram/WhatsApp
  • Google Sheets
  • Gmail
  • AI Agent/Memory

Technical approach

Connect the conversation

An n8n workflow connects Telegram/WhatsApp messaging to an LLM API and conversational memory for automated customer responses.

Keep a record & notify

Conversations are logged and stored in Google Sheets. Gmail integration provides notifications alongside the messaging workflow.
