Technical approach

Prepare network data

The NSL-KDD pipeline includes exploration, log transformations, and missing-value handling through imputation or removal.

Classify & present

SVM and Random Forest classify network traffic. The linked repository also explores KNN, distributions, correlations, accuracy, and confusion matrices. The portfolio describes a Streamlit interface for threat prediction and log analysis.

Project highlights

  • Deployed an interactive Streamlit app for real-time network threat prediction and log analysis.
